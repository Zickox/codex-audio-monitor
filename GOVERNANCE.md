# Governance

## Project model

This project is maintainer-led.

## Decision process

- Changes are proposed through issues/PRs.
- Maintainers decide based on scope, quality, and roadmap fit.
- Breaking changes require explicit release notes and migration guidance.

## Releases

- SemVer (`vX.Y.Z`).
- Release candidates via `release/*` branches.
- Hotfixes via `hotfix/*` branches.
